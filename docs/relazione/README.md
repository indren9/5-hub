## Regola di autorevolezza

Gli artifact editoriali non sostituiscono PROJECT_SOURCE_OF_TRUTH, PROJECT_CONTROL_REGISTER, decisioni ACCEPTED, baseline FROZEN o review accettate.

Le bozze devono essere riallineate quando cambia lo stato autorevole del progetto. I contenuti DRAFT/PROPOSED/REVIEW non diventano consolidati per il solo fatto di essere inclusi in questa cartella.

## Separazione delle fonti

Le fonti esterne alimentano il registro bibliografico dedicato. Le evidenze interne alimentano la matrice di tracciabilità. I due sistemi non devono essere mescolati nella bibliografia finale.
